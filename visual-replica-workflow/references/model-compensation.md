# 模型能力补偿与任务路由

## 核心原则

高保真复刻同时要求视觉识别、空间测量、文字识别、素材分离、代码生成和视觉纠错。不要假设一个模型能稳定完成全部工作，也不要用更长的总提示词掩盖不确定性。

- 能由脚本、浏览器或文件检查确定的事实，交给工具。
- 需要视觉理解的内容，拆成整图、分区和单元素的小任务。
- 模型估算必须保留来源和核验状态，不能在后续阶段自动变成事实。
- 诊断问题与修改代码分开执行，每轮限制上下文和变更范围。
- 工具结果用于提供证据，最终视觉取舍由用户判断。

## 任务分级

| 类型 | 典型输入 | 首要目标 | 实现策略 |
|---|---|---|---|
| A 类：静态宣传图 | 海报、图文长图、固定宣传页 | 固定画面的一致性 | 固定画布；复杂装饰可保留图片，文字是否真实化按用户要求 |
| B 类：真实 UI | 应用、网页、后台界面 | 结构、文本、交互和可维护性 | 核心内容使用真实组件，不用装饰截图冒充交互 |
| C 类：混合场景 | 宣传图中含手机框、卡片或功能界面 | 分区兼顾视觉与交互 | 逐区域决定真实文本、组件、SVG 或图片，不整图统一处理 |

任务类型影响素材和实现策略，不改变“参考图是唯一视觉目标”。类型不清时只问最影响下一步的问题。

## 八类失误与补偿

| 失误 | 可观察表现 | 首选补偿 |
|---|---|---|
| 视觉注意力不足 | 漏掉小装饰、细边框或遮挡 | 命名分区、局部裁剪、必要的放大副本 |
| 空间判断不准 | 坐标、宽高和间距偏差 | 坐标网格、原图测量、浏览器截图校正 |
| 文字识别不稳定 | 中文错字、标点或换行错误 | 独立文字清单；可用 OCR 加人工核验 |
| 素材边界识别不准 | 残留背景、透明边缘或细线受损 | 原图裁切优先、Alpha 检查、深浅背景看图验收 |
| 生成素材不稳定 | 表情、轮廓或颜色改变，伪透明背景 | 不替换可提取原素材；生成品单独审批 |
| 一次性代码生成不可靠 | 文件缺失、布局粗糙、路径错误 | 固定接口、分阶段和分文件交付、运行检查 |
| 多轮修改退化 | 修好一处破坏另一处 | 局部任务卡、元素冻结、检查点和回归截图 |
| 自我评估不可靠 | 没有证据就宣称完成 | 独立截图、整图与分区对比、用户验收 |

## 轻量模型准入测试

仅在启用新模型、接触新图片类型，或同类任务连续出现识别错误时进行。使用用户授权的局部图片，不额外上传或扩散材料。

1. **内容识别**：列出局部图中的元素数量、可见文字和排列顺序。观察是否漏项或稳定错字。
2. **位置分析**：使用带坐标网格的副本，指出几个元素所在区域。观察能否理解网格和相对方位。
3. **差异诊断**：提供原图局部和仅有少量已知改动的实现局部，观察能否找到真实差异。

记录具体错误，不追求通用排行榜分数。同一模型在同一图片类型上已表现稳定，或用户选择快速路径时，可跳过测试并保留常规补偿。

测试结果用于分工：

- 文字经常识别错误时，不让该模型单独负责最终文字校对。
- 网格定位不稳定时，使用测量、裁剪和截图，不要求它“再仔细看”。
- 整图差异诊断漏项时，改用更小的局部三联图。
- 两个模型给出相同坐标仍不等于测量事实；坐标必须由原图或渲染结果核验。

## 固定上下文包

每轮只提供当前任务需要的材料，不把全部历史记录反复塞给模型：

```text
analysis.json          已确认的设计规格及元素状态
text-manifest.json     本轮涉及的文字和核验状态
asset-manifest.json    本轮涉及的素材路径与批准状态
current.png            最新同视口实现截图
diff.png               当前整图或局部差异图
issues.md              本轮允许解决的问题和修改边界
相关代码文件           仅实际修改文件及理解它们所需的上下文
```

没有某份材料时明确写缺失，不生成看似完整的替代品。切换模型时也使用同一上下文包，避免依赖聊天记录中的隐性记忆。

## 小任务分工

### 视觉分析

只分析当前整图或一个分区，输出元素、文字、坐标来源和待核验项，不写代码。

### 素材处理

只处理一个或一小组素材，记录来源、透明状态和验收结果，不生成完整页面。

### 前端实现

只实现当前阶段或指定组件，遵守固定技术栈、接口和素材路径，不自行扩大任务。

### 差异诊断

只报告当前材料中可见的差异，关联元素 ID，区分布局、素材和渲染差异，不重写项目。

### 局部修复

只修改任务卡列出的元素、文件和属性，保留冻结区域，修改后等待新的截图证据。

一个助手可以承担多个角色，但不得省略产物、核验和阶段边界。

## 失败与降级

- 无法生成网格或裁剪图：保留原图，改为人工分区；相关细节标记未验证。
- OCR 不可用：使用视觉识别和人工文字核验，不编造 OCR 结果。
- 素材检查不可用：保留素材并记录未检查项，不能标记 `approved`。
- 浏览器或自动截图不可用：请求同视口手动截图；没有截图时视觉验收保持未验证。
- 分区对比不可用：退回整图叠加和人工分区检查，注明缺少机器分区证据。
- 模型持续无法完成当前小任务：缩小范围或更换分工；核心输入仍不可靠时停止受影响阶段。

不得用模型记忆、主观评价或未经确认的数字顶替缺失证据。
