# 环境配置、验证与恢复

本技能不要求账号、登录、Token、API Key、Cookie 或 MCP。视觉分析和代码生成由当前宿主能力完成；以下本地工具只支撑自动截图和图片对比。技能不会自动安装任何软件。

## python-runtime

- 用途：运行只读环境检查、参考图网格与分区裁剪、素材透明检查、固定视口截图和 PNG 对比脚本。
- 支持版本：Python 3.10 及以上的 3.x；脚本只使用 Python 标准库。图片预处理、素材检查和图片对比当前支持 8 位、非交错 PNG 的常见颜色类型，不直接读取 JPEG。
- 官方主页与下载：https://www.python.org/downloads/
- Windows 官方使用文档：https://docs.python.org/3/using/windows.html
- 登录与凭据入口：不需要。
- 权限：只需执行 Python、读取指定输入文件，并在用户批准的输出目录写入截图或对比结果。
- 配置步骤：由用户从官方下载页选择适合操作系统的 Python；安装时按官方文档配置 `python` 命令。技能不代为下载或安装。
- 凭据存储：不适用，不要在命令、源码或日志中放入任何账号凭据。
- 验证：运行 `python --version`，再运行只读环境检查。版本低于 3.10 时按 `unavailable` 处理，不尝试执行脚本。
- 故障与降级：缺少 Python 时继续视觉分析和人工实现，但自动预处理、素材检查和对比脚本标记未执行；网格与局部裁剪可改用图像编辑器，透明素材需在深浅背景上人工检查，浏览器截图可改用宿主已有能力或手动截图。
- 轮换与撤销：没有凭据可轮换。用户可通过操作系统卸载 Python，或撤销项目目录的文件权限；不要删除项目文件来“撤销配置”。
- 核验日期：2026-10-28。

## 参考图预处理与素材验收

`prepare_reference.py` 和 `inspect_assets.py` 只使用 Python 标准库，不联网、不启动子进程、不读取账号或凭据。前者输出网格、区域裁剪和区域清单，后者输出 Alpha 统计、内容边界及深浅背景预览。输出目录由用户批准，已有文件默认停止，只有明确同意覆盖时才使用 `--overwrite`。

OCR 不是必需依赖。宿主已有 OCR 或用户提供结果时，可作为文字候选并继续人工核验；没有 OCR 时仍可按局部图片转录，无法确认的文字保持待核验，不自动安装识别服务。

机器检查不自动批准素材。伪透明棋盘格、边缘质量和角色细节必须结合实际预览判断；无法确认时保持未验证。

## chromium-browser

- 用途：通过 Chrome Headless 命令行生成固定视口 PNG；也可使用宿主已有的 Playwright 或其他浏览器自动化能力。
- 支持版本：支持当前无头模式和 `--screenshot`、`--window-size` 的 Chrome 或 Chromium。脚本也会尝试常见 Edge、Chromium 安装位置，但兼容性需逐项实测。
- 官方主页与下载：https://www.google.cn/intl/zh-CN/chrome/
- 官方无头模式文档：https://developer.chrome.com/docs/chromium/headless?hl=en
- 登录与凭据入口：不需要。不要为截图登录个人账号。
- 权限：启动浏览器进程，访问用户明确给出的 HTTP、HTTPS 或 `file://` 地址，在临时目录创建隔离浏览器资料，并写入指定 PNG。
- 配置步骤：由用户从官方页面安装浏览器；优先使用宿主已有浏览器能力，避免重复安装。脚本不启动开发服务器，不安装浏览器，不读取个人浏览器资料。
- 凭据存储：不适用。URL 不得包含用户名、密码或访问令牌；需要登录的页面应由用户明确授权并使用安全会话，不在本技能中收集凭据。
- 验证：先确认浏览器可启动，再对用户批准的本地测试页截图。环境检查中的 CLI 项只检查 `chrome` 是否在 PATH；未在 PATH 不代表常见安装位置也不存在。
- 故障与降级：浏览器缺失、启动失败、超时或不兼容时，不生成假截图。改用手动同视口截图，或将视觉验收标记为未验证。
- 网络与恢复：本地 `file://` 页面不需要外部网络；HTTP/HTTPS 页面只访问用户指定地址及其页面自行请求的资源。页面故障时先修复页面或网络，不无限重试。
- 轮换与撤销：没有凭据可轮换。关闭截图进程即可终止本次任务；用户可通过操作系统卸载浏览器或撤销目录权限。临时隔离资料目录由浏览器会话结束后清理。
- 核验日期：2026-10-28。

## 图像理解能力

这是宿主模型能力，不是需要安装的包。宿主无法读取参考图时，请用户提供可读图片或已经核验的分析 JSON；不得根据文件名或记忆编造布局。没有视觉分析能力但仍获得可靠规格时，可继续素材盘点和编码，规格之外的效果标为未验证。

## 项目文件与目录权限

只读取用户提供的参考图、明确授权的项目目录和两张对比图。写入前列出源码、素材、截图或对比结果的输出位置；已有文件默认不覆盖。权限不足时保留分析结果，请用户调整目录或授权，不扫描其他个人目录寻找替代目标。

## 环境结果解释

- `ready`：机器可检查项已通过，只表示可以进入对应功能，不表示页面或视觉结果已通过。
- `partial`：核心分析和编码可继续，自动截图或对比按输出降级。
- `needs_setup`：当前必需项缺失，只展示相关配置步骤。
- `unavailable`：版本、权限、浏览器或文件状态异常，按具体原因恢复。

环境检查默认不启用网络探测，不读取凭据值，不登录、不安装、不修改配置。
