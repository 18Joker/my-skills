# 视觉逆向分析规格

## 分析任务

只分析参考图，不编写代码。输出必须让后续实现者能够定位元素、核验文字、选择素材策略并安排校正顺序。

### 输出结构

A. 画布规格：原图宽高、宽高比、目标类型、建议视口和设备像素比。

B. 页面布局树：画布、主区域、子区域、面板、卡片、文字、图片和装饰的层级。

C. 元素坐标与样式表：稳定 ID、类型、像素坐标、相对坐标、层级、遮挡、颜色、边框、圆角、阴影、字体、行高、对齐和置信度。

D. 完整文字清单：保留原顺序、标点、大小写和换行；不确定内容标为待核验。

E. 素材清单：位置、用途、目标比例、透明背景需求、实现方式和建议文件名。

F. 待确认问题：只列会影响实现或验收的事项。

G. 误差风险：按视觉影响排序，说明哪些估算最需要截图校正。

## 坐标与置信度

元素 ID 使用稳定、可读且唯一的名称，例如 `title-main`、`panel-primary`、`character-01`。后续差异报告和修正必须复用同一 ID。

- `high`：边界、文字或样式直接清晰可见。
- `medium`：主要信息可见，但尺寸或字体存在少量估算。
- `low`：遮挡、模糊或信息缺失，必须经用户或截图核验。

以下 JSON 展示格式，数值不是任何实际图片的测量结果：

```json
{
  "canvas": {
    "sourceWidth": 1536,
    "sourceHeight": 864,
    "viewportWidth": 1536,
    "viewportHeight": 864,
    "deviceScaleFactor": 1
  },
  "elements": [
    {
      "id": "title-main",
      "type": "text",
      "text": "示例标题",
      "x": 90,
      "y": 18,
      "width": 820,
      "height": 120,
      "relative": {
        "x": 0.0586,
        "y": 0.0208,
        "width": 0.5339,
        "height": 0.1389
      },
      "style": {
        "fontSize": 96,
        "fontWeight": 900,
        "lineHeight": 1.1,
        "color": "#222222"
      },
      "zIndex": 10,
      "confidence": "medium",
      "evidence": "标题可见；字体和精确边界待截图校正"
    }
  ]
}
```

相对坐标以原图宽或高为分母。不要用相对坐标掩盖像素估算的不确定性。

## 实现方式分类

为每个元素选择一种主要方式，并说明原因：

- `html-css`：文字、卡片、边框、简单背景和可交互区域。
- `svg`：轮廓明确、颜色有限的图标和曲线。
- `extract-image`：可从原图或已有资源提取的复杂插画与纹理。
- `approved-reconstruction`：用户同意后的近似重建素材。
- `undetermined`：信息不足，列出需要核验的内容。

## 可直接复用的分析提示词

```text
你是 UI 视觉逆向工程师。只分析我提供的参考图片，为后续高保真前端复刻生成可执行规格，不写 HTML、CSS 或 JavaScript。

以参考图片为唯一视觉目标，不创意改版，不优化布局，不改变文字、配色或元素关系。

1. 记录原图宽高、宽高比、目标类型和建议复刻视口。
2. 分解画布、主区域、子区域、卡片、文字、图片和装饰层级。
3. 为每个可识别元素分配唯一 ID，给出 x、y、width、height 像素坐标和相对坐标。
4. 记录间距、对齐、层级、遮挡、边框、圆角、阴影、颜色、字号、字重和行高。
5. 转录全部可辨认文字，保留顺序、标点和换行；无法确认时标记待核验，不猜测。
6. 将元素分类为 html-css、svg、extract-image、approved-reconstruction 或 undetermined。
7. 为估算标记 high、medium、low 置信度，区分可见事实与推测。
8. 输出素材清单，包含位置、用途、比例、透明背景需求和建议文件名。

按 A 画布规格、B 布局树、C 元素坐标与样式、D 文字清单、E 素材清单、F 待确认问题、G 误差风险输出。
```

## 分析复核

进入实现前检查：

- 标题、主要面板和复杂插画都有唯一 ID。
- 文字没有漏项、乱序或未经标记的猜写。
- 主区域的坐标和比例彼此一致，没有明显重叠矛盾。
- 所有低置信度关键项都已列入待确认问题。
- 目标视口与原图尺寸的关系已说明。
- 复杂素材已有提取或重建策略，没有默认全部用 CSS 或全部用图片。
