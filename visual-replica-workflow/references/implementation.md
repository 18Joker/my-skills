# 素材处理与前端实现

## 素材决策

| 元素 | 优先方式 | 核验重点 |
|---|---|---|
| 标题、正文、编号 | HTML 真实文本 | 字体、字号、换行、字距、可编辑性 |
| 卡片、面板、边框、手机外框 | HTML/CSS | 尺寸、圆角、阴影、层级 |
| 重复角色卡片和标签 | 可复用组件 | 统一尺寸与间距，不改变视觉 |
| 人物、动物、复杂角色 | 原素材或独立透明 PNG | 轮廓、表情、毛发、透明留白 |
| 简单图标、曲线 | SVG | 笔画、节点、比例和颜色 |
| 复杂涂鸦与纹理 | 提取图片 | 边缘、分辨率、平铺或裁剪 |
| 装饰性复杂内屏 | 独立图片 | 是否需要交互、裁剪区域 |
| 可交互内屏 | 真实组件 | 状态、点击区域和内容完整性 |

不要把所有装饰都拆成图片，也不要强迫所有内容变成 CSS。决定依据是视觉复杂度、交互需求、可维护性和原素材可用性。

## 素材处理顺序

1. 搜索用户明确提供的项目素材目录，复用原始文件。
2. 从参考图提取时保留原图，不覆盖源文件；记录裁剪坐标与输出尺寸。
3. 去背景后检查透明通道和边缘，不把白色角色主体误删，不损失细线、耳尾和毛发。
4. 统一素材内容框，记录透明留白；前端显示时使用明确宽高和 `object-fit`，避免拉伸。
5. 原图缺少独立素材时，先报告缺口。用户同意近似重建后才生成，并在清单中写明 `approximate: true`。
6. 多个角色分别处理，不把十几个角色合成一张图后再切割。

素材清单至少包含：

```text
id：
file：
source：original / extracted / approved-reconstruction
sourceRegion：x, y, width, height
usage：
displaySize：
aspectRatio：
transparent：true / false
approximate：true / false
notes：
```

## 布局选择

固定画布宣传页可使用设计尺寸容器，再按用户确认的规则整体缩放：

```css
.replica-canvas {
  position: relative;
  width: 1536px;
  height: 864px;
  overflow: hidden;
}

.replica-canvas__item {
  position: absolute;
  box-sizing: border-box;
}
```

绝对定位适合主要视觉元素，Grid 适合规则卡片列表，Flexbox 适合卡片内部。三者分层配合，不因使用组件或布局系统改变设计坐标。

真实响应式应用应根据目标视口设计断点、流式尺寸和内容重排。整页缩放只能用于用户确认的固定画布，不得冒充响应式实现。

## 编码顺序

1. 搭建主区域和层级正确的结构版本。
2. 加入文字、卡片、边框和背景样式。
3. 集成已有素材并修正内容框、透明留白和裁剪。
4. 检查字体加载、字体回退、换行、层级和遮挡。
5. 启动页面，处理缺失资源和关键控制台错误。
6. 在相同视口下截图，再进入差异修正。

为关键元素保留稳定 class 或数据标识，与分析 ID 对应。把颜色、间距、圆角、字体等共享值集中维护。

## 可直接复用的编码提示词

```text
基于参考图片、已核验视觉分析规格和素材目录实现高保真前端页面。

以参考图片为唯一视觉目标，不改版、不美化、不添加未经要求的元素。遵守目标视口、画布尺寸、元素坐标、比例、层级和文字内容。

优先复用已有素材，不擅自生成相近插画。复杂插画用图片，简单几何用 CSS 或 SVG，文字使用真实文本节点。不得把整张参考图设置成页面背景冒充复刻。

先完成布局骨架，再加入文字和样式，随后集成素材。重复卡片可封装组件，但不得改变视觉。关键元素使用与分析 ID 对应的稳定选择器，共享视觉值集中维护。

完成后启动页面，记录启动方式、缺失资源和关键控制台错误。在参考图相同视口下截图，并列出尚未达到目标的视觉差异。没有实际截图时明确写未完成视觉验证，不宣称 1:1。
```

## 实现复核

- 页面没有整图背景或不可编辑的大块文字截图。
- 复杂素材来源可追溯，近似素材均已获得同意并标记。
- 图片没有异常拉伸，透明留白未被误当作内容尺寸。
- 主要元素可通过稳定 ID 定位，差异报告能映射回代码。
- 字体加载失败时有记录，没有把回退字体结果当作原字体。
- 页面启动方式和依赖说明完整，运行失败时明确标为未验证。
