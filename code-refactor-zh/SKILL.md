# 批量代码重构工具

跨文件批量重构代码，支持重命名、模式替换、API 升级等操作。

## Tools Required
- read
- write
- exec

## 执行模式

- **1-9 个文件**：使用 Grep + Edit 精准替换
- **10 个文件以上**：自动切换批量执行模式，高效处理

## Usage

- "把代码库里所有 getUserInfo 函数重命名为 fetchUser，帮我批量替换"
- "升级了 SDK，帮我把所有旧版 API 调用方式替换成新版本"
- "统一命名规范，把所有驼峰命名的变量改成下划线格式"

## Examples

输入：`把项目里所有 axios.get/post 调用替换成我们封装的 request.get/post，同时保留参数不变`

输出：
1. 扫描受影响文件（共 23 个）
2. 自动切换批量模式
3. 逐文件执行替换，保留原有参数结构
4. 输出变更摘要：23 个文件 / 67 处替换 / 0 个错误
5. 列出需要人工确认的边界情况（如动态调用、条件分支内的调用）
